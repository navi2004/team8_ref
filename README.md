# Bash 파일 검색 도구

공개SW실무 발표 실습용 Bash 파일 검색 도구입니다. 디렉터리 경로를 입력하고 메뉴를 선택해 확장자 또는 수정 시각을 기준으로 파일 목록을 찾습니다.

## 기능

- 입력한 확장자에 해당하는 파일을 검색합니다.
- 최근 약 72시간 이내에 수정된 일반 파일을 검색합니다.
- 잘못된 경로나 검색 결과가 없는 경우 안내 문구를 출력합니다.
- 파일 이름과 수정 시각으로 목록을 찾으며, 파일 내용이나 보안 상태는 분석하지 않습니다.

## Ubuntu 실습 준비

실습은 VMware 안의 Ubuntu에서 진행합니다. 아래 준비를 미리 끝내 두면 실습 중 네트워크에 연결하지 않아도 됩니다.

### 1. 실습 폴더 만들기

Ubuntu에서 터미널을 열고 홈 디렉터리로 이동한 뒤 폴더를 만듭니다.

```bash
cd ~
mkdir -p ~/shell-demo
```

- `cd ~`는 홈 디렉터리로 이동합니다.
- `mkdir -p`는 `shell-demo` 폴더를 만듭니다. 이미 폴더가 있어도 다시 실행할 수 있습니다.

### 2. 스크립트 파일 만들기

GitHub 저장소에서 `file_search.sh` 파일을 열어 코드 전체를 복사합니다. 다음 명령으로 Ubuntu 안에 파일을 만듭니다.

```bash
nano ~/shell-demo/file_search.sh
```

편집기가 열리면 복사한 코드를 붙여 넣습니다. 저장은 `Ctrl+O`, `Enter`, 종료는 `Ctrl+X`를 누릅니다.

> 실습 당일 네트워크가 끊겨도 진행할 수 있도록 이 파일을 발표 전에 Ubuntu에 준비해 둡니다.

### 3. 샘플 파일 만들기

검색 연습에 사용할 파일은 `~/shell-demo` 안에만 만듭니다.

```bash
touch ~/shell-demo/report.txt ~/shell-demo/note.txt
touch ~/shell-demo/run.sh ~/shell-demo/"team note.txt"
touch -d '5 days ago' ~/shell-demo/old.txt
```

- `report.txt`, `note.txt`, `run.sh`, `team note.txt`는 최근 수정 파일로 사용합니다.
- `old.txt`의 수정 시각은 5일 전으로 설정해 날짜 검색에서 제외되는지 확인합니다.
- `team note.txt`는 파일 이름에 공백이 있어도 검색되는지 확인하는 샘플입니다.

### 4. 파일 목록 확인하기

```bash
ls -l ~/shell-demo
```

샘플 파일 목록을 확인합니다. `file_search.sh`도 이 폴더에 만들었으므로 목록에 함께 보입니다.

### 5. 실행 권한 설정하기

```bash
chmod +x ~/shell-demo/file_search.sh
```

`chmod +x`는 스크립트를 실행할 수 있도록 권한을 설정합니다. 이미 실행 권한이 있어도 다시 실행해도 됩니다.

## 실행 방법

홈 디렉터리에서 스크립트를 실행합니다.

```bash
cd ~
./shell-demo/file_search.sh
```

검색 디렉터리를 입력하라는 메시지가 나오면 다음과 같이 입력합니다.

```text
shell-demo
```

`read`로 입력한 `~/shell-demo`는 Bash가 자동으로 홈 디렉터리 경로로 바꾸지 않습니다. 위처럼 홈 디렉터리에서 실행하고 `shell-demo`라고 입력하세요.

## 테스트 방법

프로그램은 실행할 때마다 한 가지 검색 메뉴를 선택합니다. 각 테스트 후 다시 실행해 다음 검색을 진행합니다.

### 테스트 1: `txt` 파일 찾기

1. 메뉴에서 `1`을 입력합니다.
2. 확장자로 `txt`를 입력합니다.

결과에는 다음 네 파일이 포함됩니다.

```text
report.txt
note.txt
team note.txt
old.txt
```

`old.txt`도 `.txt` 파일이므로 확장자 검색에는 포함됩니다. 출력 순서는 환경에 따라 달라질 수 있습니다.

### 테스트 2: 검색 결과가 없는 확장자 찾기

1. 프로그램을 다시 실행합니다.
2. 메뉴에서 `1`을 입력합니다.
3. 확장자로 `pdf`를 입력합니다.

준비한 `.pdf` 파일이 없으므로 다음 안내가 나옵니다.

```text
조건에 맞는 파일이 없습니다.
```

### 테스트 3: 최근 수정 파일 찾기

1. 프로그램을 다시 실행합니다.
2. 메뉴에서 `2`를 입력합니다.

최근에 만든 파일과 `file_search.sh`가 결과에 포함됩니다. `old.txt`는 5일 전에 수정했으므로 제외됩니다. `-mtime -3`은 달력 날짜 기준 오늘과 이전 이틀이 아니라 대략 최근 72시간을 기준으로 합니다. 결과 순서는 고정되지 않습니다.

### 테스트 4: 잘못된 디렉터리 입력하기

프로그램을 다시 실행하고 존재하지 않는 경로를 입력합니다.

```text
no-such-folder
```

다음과 같이 안내한 뒤 종료합니다.

```text
디렉터리를 찾을 수 없습니다: no-such-folder
```

## 실습 범위와 주의점

이 도구는 디렉터리 아래의 파일을 이름 또는 수정 시각으로 검색해 목록으로 보여줍니다. 파일 내용을 읽거나 악성 코드 등 보안 문제를 진단하지 않습니다. 스크립트 실행 자체에는 네트워크 연결이 필요하지 않습니다.
